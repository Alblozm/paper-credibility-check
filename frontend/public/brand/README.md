# PaperTrace brand assets

These PNGs preserve the PaperTrace concept selected on 25 October 2026: a folded paper,
two text lines and a circular evidence anchor, with the original blue wordmark.
They were extracted from the selected concept using the built-in image generator.

- `papertrace-logo.png`: transparent horizontal lockup, 2160 × 728 px.
- `papertrace-icon.png`: transparent standalone mark, 1254 × 1254 px; used for the favicon and touch icon.

The lockup includes transparent gutters. The `.cs-brand-lockup` viewport shows the
source region x=72, y=150, width=2048, height=448 without stretching the artwork.
It displays at 128 × 28 CSS px, or 110 × 24 on narrow screens. Below 381 px, the
same artwork is framed to show just its 28 px mark so the assessment tabs remain
reachable. Keep the icon and wordmark together at larger sizes; do not replace
the wordmark with a different font.

Product name: **PaperTrace**. Tagline: **Follow the evidence.**
