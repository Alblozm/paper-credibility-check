# data目录说明

本目录保存基准数据集的可版本化数据，不保存用户上传的私人PDF。

## 子目录

- `manifests/`：论文主清单及数据集版本配置。
- `source_snapshots/`：来源版本、URL、哈希和存储策略记录。
- `parsed/`：经过质量门检查的章节、正文块和图表结构化结果。
- `annotations/`：两名标注者的独立结果和最终仲裁结果。
- `quality_reports/`：缺失字段、解析错误、评分分歧和验证结果。

## 不应放入本目录的内容

- 原始PDF；
- API密钥和`.env`文件；
- 临时下载缓存；
- 没有来源信息的手工复制文本；
- 无法确认属于哪个论文版本的评分。

每条正式数据必须能够追溯到`paper_id`、`paper_version_id`、来源URL和获取日期。
