# 人工标注目录

## 目录分工

- `annotator_a/`：标注者A的独立评分。
- `annotator_b/`：标注者B的独立评分。
- `adjudicated/`：双方讨论后形成的最终基准评分。
- `ai_trial/`：流程试验产生的AI暂定评分，不是Gold标签。

## 标注原则

两名成员必须先独立完成评分，不能共同编辑同一份初始答案。每篇论文应包含五个固定维度、理由、置信度和证据位置。

建议文件名统一为：

```text
paper_001.json
paper_002.json
```

如果分数不同，应记录原始分数、分歧原因和最终决定，不得删除或覆盖原始标注。
